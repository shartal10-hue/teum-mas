# teum-mas

## עמודי מעבדות (Laboratory profile pages)

תיקיית [`labs/`](labs/) מכילה מערכת עמודי מעבדה מבוססת-נתונים:

- **[`labs/index.html`](labs/index.html)** — עמוד רשימה: כרטיס לכל מעבדה עם לוגו, שם, תיאור קצר וחברה מובילה, וקישור לעמוד המעבדה המלא. כולל חיפוש.
- **[`labs/lab.html`](labs/lab.html)** — עמוד מעבדה: נפתח עם `?id=<מזהה>` ומציג את כל שדות המעבדה.
- **[`labs/data.js`](labs/data.js)** — מקור הנתונים היחיד. כל מעבדה היא אובייקט במערך `LABS`.

### הוספת מעבדה
מוסיפים אובייקט חדש למערך `LABS` בקובץ `labs/data.js` עם `id` ייחודי. עמוד הרשימה
והקישורים נוצרים אוטומטית. שדות חסרים מוצגים כ-"—".

### שדות המעבדה
שם המעבדה · לוגו · תיאור קצר · הצעת ערך ייחודית · חברה עסקית מובילה · שותפים ·
מימון ייעודי · פיתוח עסקי · איפה יושבים · כנס שנתי בחו"ל · אתגרים ·
חוקרים באוניברסיטת בן-גוריון · מכוני מחקר · מחלקות · פקולטות ·
תשתיות TRL 2-5 · תשתיות TRL 6+ · תשתיות ברובע · תשתיות בבאר שבע · תשתיות בנגב ·
מימון מרשות החדשנות · מימון מהוריזון אירופה · מוביל מדעי

> הנתונים הנוכחיים ב-`data.js` הם דוגמה להמחשת המבנה — יש להחליפם בנתונים אמיתיים.
